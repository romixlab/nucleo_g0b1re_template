# Features

What the template ships, with stable IDs per area. Status: ✅ works, 🧪 built, not yet run on a board, 🚧 in
progress, 📋 planned, 🐛 bug. Update this file in the same commit as the code; never renumber or reuse an ID.

## FW: firmware (`firmware/`)

| ID | Feature | Status | Notes |
|---|---|---|---|
| FW-1 | embassy on STM32G0B1RE, defmt log over RTT | 🧪 | generated by embedded_bedrock's firmware template, see `bedrock_fw.json` |
| FW-2 | WireWeaver device API served over RTT (channels `ww_up` / `ww_down` next to the defmt channel) | 🧪 | `firmware/src/ww.rs` |
| FW-3 | Settings store in flash (`ww_settings`, 8 KiB at the end of bank 2, ECC-safe reads) with the board's label | 🧪 | `firmware/src/settings.rs` |
| FW-4 | `cnt` event counters in RAM and in TAMP backup registers (survive a reset) | 🧪 | `cnt tui` shows them |
| FW-5 | Crash capture: HardFault and panic record kept across a reset, reset cause, boot counter | 🧪 | `bedrock_crash`, `firmware/src/last_reset.rs` |
| FW-6 | ES0548 (dual-bank prefetch) guard: flash prefetch on, code kept in bank 1 by a link-time assert | ✅ | `firmware/memory.x` |
| FW-7 | Clock tree for the Nucleo (HSI 16 MHz by default; PLL to 64 MHz) | 📋 | `TODO` in `firmware/src/main.rs` |
| FW-8 | User button B1 (PC13) in the API | 📋 | an example of adding a property |
